# Ani-plan (AnimalHack 2026)

A comprehensive and user-friendly animal nursery and sanctuary management system. Built for **AnimalHack 2026**.

## 🌟 Inspiration
Inspired by garden management systems (like Green Plan), Ani-plan brings the same level of care, monitoring, and detailed planning to animal sanctuaries, farms, and nurseries. 

## ✨ Features
1. **Habitat & Enclosure Setup:** Allocate virtual enclosures, set environment specs, and manage zoning (breeding, quarantine).
2. **Animal Profiles:** Onboard animals, track batches/flocks, and log initial vitals.
3. **Care Schedules:** Automated reminders for feeding, hydration, and routine care.
4. **Growth & Production:** Monitor life cycles, weight tracking, and breeding management.
5. **Health Management:** AI symptom checker, vaccination logs, and quarantine alerts.
6. **Analytics:** Visual dashboards for growth charts and overall nursery health scores.

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 💻 Tech Stack
- Frontend: Next.js (React), Tailwind CSS, Lucide Icons
- Backend (Planned): Node.js API Routes / Python
- Database (Planned): PostgreSQL / MongoDB
